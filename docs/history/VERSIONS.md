# 历史版本与证据边界

本项目保留 14 个已有源码版本快照：0.1.0、0.1.1、0.2.0、0.3.0、0.4.0、0.4.1、0.4.2、0.4.3、0.4.4、0.4.6、0.4.7-debug、0.4.8、0.4.9、0.4.11。当前持续开发版本为 0.4.11，历史 0.4.7 的快照名称为 0.4.7-debug。

0.4.5 与 0.4.10 缺少独立源码快照。相关发布说明来自后续源码包，仅能说明当时记录的变更方向，不能据此确认完整源码内容、发布产物或原始开发过程，也不能补造对应提交或标签。

版本快照不是逐行开发历史。提示驱动的 AI 生成与迭代形成了项目代码，公开历史不应被解释为个人逐行手工编写的证据。快照的版本名称与公开发布说明有对应关系，但功能正确性仍需单独验证。

历史隐私重写可能改变提交标识，不能依赖旧克隆或旧提交标识继续协作。本目录不保存旧迁移报告、导入清单、归档校验值或个人机器验证记录。协作边界见 [隐私说明](../PRIVACY.md)，演进概要见 [发布说明索引](../RELEASES.md)。
