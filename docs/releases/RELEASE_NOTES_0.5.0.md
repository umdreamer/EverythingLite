# Everything Lite 0.5.0

本版本新增索引更新日志、日志保留设置和本应用打开记录。项目采用 MIT 许可证，通过 Vibe Coding 方式开发，并非个人逐行手工编写。

## 新增功能

- “工具 → 索引更新日志…”按本地日期显示索引任务开始、待更新、重试与恢复；当前待更新范围和历史记录分区显示。日志不保存搜索关键词。
- 可选择不自动删除，或保留最近 7、30、90、365 天；到期清理保留当天记录。指定日期可在确认后手动删除。
- 结果“状态”列显示本应用最近一次被系统接受的打开请求时间。选中可访问结果时，后台核验原路径；离线和仅云端记录保持原有状态。

## 数据与兼容性

每日索引日志位于应用数据目录的 `index-update-logs/`，打开记录位于同目录的 `open-history.db`；均与搜索索引分离。搜索日志仍只保存在当前窗口内存中。没有本应用打开记录不能证明文件从未被其他程序打开。路径核验不删除索引记录。

已有索引和设置继续使用原路径。本版本没有更改索引格式。macOS 是本版本的主要验证平台；Linux 桌面行为需在目标系统另行验收。
