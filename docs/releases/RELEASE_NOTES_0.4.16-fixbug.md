# Everything Lite 0.4.16-fixbug

Everything Lite 由 Vibe Coding 形成，非个人逐行手工编写。源码使用 MIT 许可证。本版本用于本地试用，尚未推送至 GitHub。

后台索引任务结束后的条数统计是可选操作。统计读取失败不再覆盖任务的实际结果，也不会被显示为“索引同步失败”。

文件变化扫描首次未完成时，状态栏显示“索引更新重试中”；最多自动重试两次。重试耗尽后才显示“部分索引未更新”，并在“工具 → 索引状态”保留受影响范围和原因。已成功索引过的来源若后续扫描未完成，其搜索结果显示为“缓存结果（更新未完成）”。缓存仍可搜索，但可能过期；真实扫描失败没有被当作成功。

自动化检查见[测试报告](../TEST_REPORT.md)。真实大型索引的扫描失败原因和桌面交互仍需目标环境核对。
