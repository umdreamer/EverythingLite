# Everything Lite v0.4.3 Release Notes

## 目标

本版本只解决一个问题：CLI 能正确返回某些中文关键词（例如“砀例甲”），但 GUI 不显示结果。

## 修复

1. 默认 GUI 搜索与 CLI 使用完全相同的 `SearchEngine::search(std::string)` 入口。
2. 结果是否进入表格只由 request ID 判断，不再使用可能受 Qt/IME 文本状态影响的 signature 二次校验。
3. GUI 查询执行 NFC Unicode 归一化，并移除常见零宽格式字符。
4. 新增“工具 → 最近搜索诊断…”。诊断窗口显示：
   - 搜索框原文；
   - 归一化查询；
   - UTF-8 十六进制；
   - 当前文件/文件夹范围；
   - Match Path 状态；
   - 请求 ID；
   - 核心执行模式；
   - 核心返回行数；
   - 表格模型行数；
   - 查询耗时。

## “砀例甲”正确 UTF-8

`砀例甲` 的 UTF-8 应为：

```text
e7 a0 80 e4 be 8b e7 94 b2
```

如果 GUI 仍不显示结果，请搜索“砀例甲”后立即打开“工具 → 最近搜索诊断…”。如果“核心返回”大于 0 但“模型当前行数”为 0，问题位于模型/UI；如果核心返回为 0，则可用显示的 UTF-8 和执行模式继续定位输入或过滤条件。

## 继承修复

保留 v0.4.1 的 SQLite 查询取消/request ID 机制，以及 v0.4.2 的 FSEvents 后台刷新隔离。
