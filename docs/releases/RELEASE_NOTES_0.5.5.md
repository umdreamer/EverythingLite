# Everything Lite 0.5.5

本维护版本汇总 0.5.1 至 0.5.5 的 Bug 修复。项目采用 MIT 许可证，通过 Vibe Coding 方式开发，并非个人逐行手工编写。

## 目录与来源

保存或启动后，活动目录清单与配置目录在后台同步。新增目录自动建立索引；首次扫描未完成的本地目录在重启后仍可处理。空目录列表不再恢复默认目录，也不会退回搜索全部历史缓存。

数据库中的活动目录与历史来源缓存分开显示。历史来源可能归属某个活动根目录，或属于尚未启用的缓存；来源身份、NAS 和移动存储离线缓存不会因移除目录而被删除。已有文件记录不复制、不迁移。

相同目录配置不会反复写库；来源元数据同步不触发全库文件统计。后台同步保留当前查询、分页和结果选择。

## 累计修复

0.5.1 保留索引变化时的活动搜索结果；0.5.2 修复部分扫描和配置搜索范围；0.5.3 改进具体扫描原因、可访问兄弟目录的更新及嵌套来源覆盖；0.5.4 保护扫描时被替换的目录。详细记录见 CHANGELOG。

## 范围

统一设置界面和分级更新策略属于后续 0.6.0，本维护版本不包含这些新增功能。已有索引和设置路径继续使用。验证使用合成目录、独立数据库和配置；真实 NAS、真实大型用户索引与独立签名分发不在自动测试验收范围内。实际构建和测试结果见测试记录。
