# Mac 原生目录能力只读验证计划

**目标：** 在已确认授权的开发流程中取得实际原生接口证据，区分直接 helper 的状态与注册 Qt GUI 上下文中的实际 AX 调用结果。检查结果不等于双向目录联动完成。

**实现：** 同一应用新增严格参数隔离的 `--directory-sync-native-probe`，创建独立隐藏 Qt GUI 上下文后执行只读原生调用，不创建主窗口、索引或设置。默认只查询当前前台应用的 focusedWindow；只有标准 open-panel／save-panel 才读取有界控件元数据。每个 AX 元素设置消息超时，每次调用前检查截止时间。权限状态与实际 API 错误分别报告，不自动请求权限或绕过系统策略。

自有标准面板实验仅接受专用 fixture bundle 的 PID 与规范合成临时目录，拒绝其它目标。输出角色、脱敏标识、属性名称及合成目录匹配布尔值，不输出目录、标题、文件名或属性原值。不能根据选中文件或侧栏 URL 推断当前目录。本阶段不执行 AX 写入、键盘事件、Finder 导航或打开／保存操作。

- [x] 真实可执行文件的无动作探针先取得缺少 JSON 的行为失败基线，再实现固定版本有界协议和参数隔离回归。
- [x] 严格 GUI 构建与原生、权限及窗口定向回归通过；自有面板实验使用隔离环境，自动取消，不写入实际用户配置或索引。
- [x] 只读规范与质量审查、独立复验后本地提交及记录实际能力；实际标准控件识别和导航验收另行完成。

**实测边界：** 实现提交 `8c52431` 已通过规格与独立质量审查；控制代理定向复验 3/3，约 5.22 秒。LaunchServices 隐藏启动实际 GUI 和三类自有面板均返回 AX `-25211`，未读取 focusedWindow。自有面板的目录及保存框文件名由所属应用确认，不能作为跨进程目录识别证明。三类面板均自动取消，未创建索引。原生目录识别与导航未验收。
