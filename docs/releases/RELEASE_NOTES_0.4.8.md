# Everything Lite 0.4.8 发布说明

## 变更范围

UTF-8 拆词修复。

`splitQuery()` 改为明确识别 ASCII 空白字节：TAB、LF、VT、FF、CR 与 SPACE，不使用受 locale 影响的逐字节空白分类拆分 UTF-8。

高位字节作为查询内容保留。例如合成字 `匠` 的 UTF-8 为 `E5 8C A0`，末尾 `A0` 不能在字符内部被当成分隔符。合成查询 `砀例甲` 与 `示例工匠` 可用于覆盖三字及四字词拆分场景；UTF-8 编码的 U+00A0 也不属于 ASCII 分隔符。

回归场景检查单词完整性、ASCII 空白组合拆词及查询解析。修复范围是 UTF-8 拆词，不代表已经支持全部 Unicode 分词或语言学匹配。Search Trace 保留。
