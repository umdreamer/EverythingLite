# 搜索日志与状态栏设计

状态栏从左到右固定为消息、搜索结果与耗时、同步、文件监听、搜索筛选。消息占剩余宽度，所有区域只显示一行；超出宽度的内容以省略号截断，完整文字通过悬停提示或菜单详情查看。同步失败区域只显示失败数量，不再拼接路径；旧缓存保留，首次失败后最多自动重试两次。相关文件事件或手动重建可以重新触发失败范围。

“搜索 → 搜索日志…”列出本次运行中最近 100 次搜索。每条记录包含开始时间、查询、范围、筛选、分页偏移、状态、耗时、返回数量、搜索开始时的同步失败数量和错误详情；选择记录显示完整详情。被新查询替代的搜索记为取消，索引版本变化记为待重试，未索引文件夹中的搜索记为未执行。日志只保存在窗口内存中，不写入数据库、偏好设置或磁盘；用户可在窗口中清空。单纯修改输入文字而未触发搜索时，不建立记录。

验证包括：同步失败不改变搜索结果与耗时区域；所有状态区单行且有宽度上限；完整错误仍可在“索引状态…”查看；每次实际搜索建立并完成一条记录，取消和失败保留原因；日志上限和清空动作生效；GUI 测试不改写真实偏好设置。
