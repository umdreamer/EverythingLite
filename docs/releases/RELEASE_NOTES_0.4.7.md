# Everything Lite 0.4.7 发布说明

## 变更范围

Search Trace 诊断。

增加可启用的 Search Trace，覆盖查询输入、解析词、数据库状态、SQL 与参数、结果数量及模型更新。增加独立 CLI `probe-search`，并在调试模式中对照同一数据库与查询参数。

`run-macos-debug.sh` 保存本地日志。诊断可能包含可执行文件、数据库和结果路径及关键词；原始日志不能上传。不同层的数量差异只提供排查方向，不足以单独确认 FTS、事务或 UI 为根因。

已有源码快照名称为 0.4.7-debug。Trace 功能在后续版本保留；它不等于运行时日志已经脱敏。

## 验证与使用边界

本说明保留功能演进，不沿用个人机器数据或历史通过率作为当前验证结果。未复测的行为不得标记为通过。当前构建步骤见 [开发指南](../DEVELOPMENT.md)，验证范围见 [测试说明](../TEST_REPORT.md)，版本来源见 [历史版本](../history/VERSIONS.md)。

公开复现使用独立数据库及合成目录；不上传日常索引或原始 Trace。当前运行方式应按 0.4.11 文档执行，旧版本策略仅用于理解演进。
