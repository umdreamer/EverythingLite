# Everything Lite 0.4.15

本项目由 Vibe Coding 形成，非个人逐行手工编写。源码采用 [MIT License](../../LICENSE)。本版本修复 Mac 的索引维护、排除规则编辑和重复搜索结果；Linux 共用源码，但本版本未重新验证 Linux 桌面交互。

## 变化

重建索引时，状态栏显示运行进度和完成结果。索引存储窗口改用快速空间统计，避免打开时遍历大库。Mac 图形界面的 `storage optimize` 和 `storage compact` 不再自动创建重复备份；CLI 显式使用 `--backup` 时仍可保留恢复副本。已有备份不会自动删除。

排除规则的目录和文件路径现在可直接输入，也可使用选择器填写。保存时窗口显示处理状态，避免误认为无响应。搜索结果按完整路径合并重复记录，防止同一文件与位置显示两条。

## 验证与限制

本版本的自动化验证见[测试报告](../TEST_REPORT.md)。实际大索引响应时间、Finder 与原生文件选择器联动、真实 NAS 以及独立签名分发包仍需目标环境验收。历史 0.4.5 与 0.4.10 标签由后续取得的独立源码 ZIP 脱敏补录，不代表原始开发时间线。
