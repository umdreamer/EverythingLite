# Everything Lite 0.2.0 发布说明

## 变更范围

本机构建与基础索引。

本版本将 macOS 本机构建与独立分发部署分开，构建脚本不默认执行 `macdeployqt`。FSEvents 使用 dispatch queue 调度接口。基础能力包含名称与路径过滤、属性搜索、结果排序和系统打开操作。

当时 GUI 返回窗口最多 1000 条，排序针对已加载结果。普通子串与路径搜索尚依赖兼容 SQL，不能据此承诺大索引响应速度。当前分页机制已在后续版本调整。
