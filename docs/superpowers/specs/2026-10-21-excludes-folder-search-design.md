# Everything Lite 0.4.14：排除规则与指定文件夹搜索

## 目标与边界

0.4.14 为 Mac 图形界面提供排除规则管理和指定文件夹搜索，并让 Core、CLI 与 GUI 使用同一语义。排除规则沿用现有精确目录、精确文件、文件夹过滤器和文件过滤器，保留 `*`、`**`、`?` 通配规则，新增 `regex:` 正则过滤。指定文件夹搜索只查询已有索引，不自动增加索引根或扫描磁盘。Linux 源码保持可构建，但本阶段以 Mac 构建和回归为发布条件；Linux 桌面交互另行验收。

本版本不增加 Everything 的 Include Only、隐藏/系统属性过滤、正文搜索或搜索框通用正则语法。现有离线来源缓存策略保持有效；指定文件夹搜索允许返回该文件夹下仍保存在索引中的离线记录，并沿用现有来源/状态标记。

## 方案选择

采用 Core 层 PCRE2 编译排除正则、数据库查询层限制文件夹范围、GUI 层编辑和选择。PCRE2 与 Everything 官方说明所用的 PCRE 语法族接近，并使无 Qt 的 Core/CLI 共用规则。GUI 取回结果后再过滤虽然改动较少，却会破坏分页和结果数量，并增加全库查询成本；仅使用 C++ 标准正则也不能承诺 PCRE 语法兼容。本版本明确记录 PCRE2 与 Everything 版本间可能存在的具体语法差异，不宣称完全兼容。

## 排除规则

数据库继续使用现有 `ExclusionRules` 四类字段，不迁移旧规则。`regex:` 仅用于文件夹/文件过滤器，不用于精确路径列表。多个过滤器以分号分隔；含分号的表达式沿用现有整项引号和双引号转义。正则按 PCRE2 UTF-8 模式编译，匹配时使用不区分大小写模式。表达式含 `/` 时匹配规范化完整路径，否则匹配名称；与现有通配过滤器的目标选择一致。正则不把反斜杠自动改成 `/`，以保留 `\d` 等转义。文件夹过滤器命中某层文件夹时，排除该层及全部后代；文件过滤器只排除命中的文件。精确路径与现有通配规则语义保持不变。

保存前在 Core 验证完整策略：无效 UTF-8、空正则、编译错误及不支持的前缀返回可读错误，且不修改数据库。编译后的正则随策略实例复用，不为每个文件重新编译。设置 PCRE2 匹配和递归/深度上限；超限是明确的扫描或清理错误，不能默默当成“不匹配”。遇到文件系统中的非法 UTF-8 名称，正则不匹配该名称，原有精确路径与通配处理不变。新增排除项时，现有事务性策略保存会清理已索引命中项；删除或放宽规则不能从数据库凭空恢复旧项，GUI 明确提示重新扫描，提供现有重建入口。扫描和文件事件仍使用同一策略修订。

GUI 设置窗口从数据库读取和保存四类规则，提供添加/移除精确目录、添加/移除精确文件及编辑两类过滤器。文件夹和文件路径可用系统选择器输入；过滤器允许直接编辑，展示 `regex:` 和通配示例。保存先验证规则，再显示被清理的记录数并刷新结果；错误时保留编辑内容，显示具体错误。CLI `excludes set/show/clear` 保持既有命令和“set 替换完整策略”的约定，并更新帮助文字。

## 指定文件夹搜索

GUI 在搜索栏附近显示当前范围、选择文件夹和清除范围。选择器只负责选路径，不改变索引配置。范围为空时搜索全索引；范围非空时仅返回该文件夹的后代，文件夹自身不算“其内部”。路径先规范化；`/docs` 不匹配 `/docs-old`，含空格、中文、`%`、`_` 的路径按字面处理。所选文件夹未纳入任何索引根时，界面提示“该目录未索引”，结果为空；不启动自动扫描。已索引但当前卸载的来源仍可从保留的索引中搜索，并显示离线状态。文件夹范围与现有关键词、文件/文件夹类型、匹配路径和分页同时生效。

范围作为结构化参数进入 `SearchOptions` / `SearchQuery`，在数据库 SQL 的 `LIMIT/OFFSET` 之前过滤；使用已有 `files.path` 索引和路径边界约束，不能用 `path:` 子串或 GUI 后过滤代替。CLI 搜索命令提供 `--in-folder PATH`，与 GUI 使用相同查询条件。范围进入搜索签名；切换范围时取消或丢弃旧请求，清空旧页，从第一页重查。GUI 保存当前范围；书签保存范围并在载入时恢复。旧书签缺少该字段时按全索引搜索，不改变旧书签其他字段。

## 失败处理与验收

无效或不可用的文件夹路径给出明确提示；路径选择取消不改变当前范围。正则错误不保存策略；数据库保存或扫描失败给出错误且不报告成功。规则放宽后提示重新扫描；若离线来源不可用，保留现有离线索引，不因排除设置自动删除来源。

Core 回归覆盖精确路径、通配与 PCRE2 混用、名称/完整路径、目录后代、非法正则和匹配上限、策略修订与清理。搜索回归覆盖路径边界、特殊字符、离线记录、FTS 与直接查询、分页和 CLI/GUI 一致性。GUI 回归覆盖设置保存/错误、范围切换时旧结果抑制、书签和重启恢复。发布前执行 Mac Debug 全量 CTest、Mac Release 构建、版本与隐私检查；通过后更新发布说明并标记 `v0.4.14`。
