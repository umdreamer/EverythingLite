# Everything Lite 0.4.1 发布说明

## 变更范围

搜索调度与诊断。

调整旧查询结束后的调度，避免直接查询尚未完成的输入文本。引入 request ID 防止过期结果覆盖，并在当时的异步搜索链路中使用 SQLite progress handler 取消过时查询。

当时短词自动搜索延迟为 240 ms，其他词为 100 ms；后续版本改为统一 800 ms。GUI 与 CLI 统一默认数据库解析，CLI 增加 `db-path`、`--db` 与 `check-search-index`。CLI 显式 `--db` 优先于环境变量，环境变量优先于平台默认路径。

以上是该历史版本的改动，不能把其取消策略或延迟参数当成 0.4.11 当前 GUI 行为。

本说明保留功能演进，不沿用个人机器数据或历史通过率作为当前验证结果。未复测的行为不得标记为通过。当前构建步骤见 [开发指南](../DEVELOPMENT.md)，验证范围见 [测试说明](../TEST_REPORT.md)，版本来源见 [历史版本](../history/VERSIONS.md)。
