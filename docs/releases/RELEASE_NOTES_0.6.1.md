# Everything Lite 0.6.1

本版本为性能 Bug 修复，不增加功能或改变应用架构。项目采用 MIT 许可证，通过 Vibe Coding 方式开发，并非个人逐行手工编写。维护者已确认版本 0.6.1，完整验收后创建修复标签。

普通短名称查询在来源范围足够大、索引存在且查询条件适用时，先按现有名称索引筛选，再读取文件属性与来源。小来源或未选来源统计未知时继续使用原计划。FTS、路径、指定文件夹、紧凑存储及其他选择性查询保留原访问路径。

路径更新策略避免对每条记录重复解析同一组件，Library 边界在构造时计算一次。普通实时及周期更新完成后不再无条件全库计数，明确的完整扫描继续更新统计。原有扫描范围、隐藏属性处理、离线缓存、搜索结果和界面保持。

本版本不自动迁移或压缩真实数据库，不自动重建日常索引。核心热点夹具结果不能推断整个搜索的固定加速倍数，最终测试与未验收范围见测试记录。按修复发布规则，本次仅创建 tag，不单独创建 GitHub Release。
