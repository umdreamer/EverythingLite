# Everything Lite 0.4.13

本版本通过 Vibe Coding 方式开发，采用 MIT 许可。以 Mac 索引维护为重点；Linux 平台仍共用源码，但本版本未重新验证 Linux 构建与桌面交互。

## 变化

嵌套索引根目录按来源归属扫描，避免父来源重复收录已交给子来源的内容。搜索分页使用稳定排序和来源身份；数据库在分页期间变化时，界面重新加载结果。

新增索引空间统计、显式 SQLite VACUUM 和目录字典存储格式迁移。Mac 界面提供后台维护、取消和分项占用报告。修改主库前会创建并验证恢复备份；备份清理要求保留至少一份与当前主库文件身份匹配、可独立读取的来源凭证备份。索引格式迁移须主动启动，普通启动不自动升级数据库。细节见[索引存储](../INDEX_STORAGE.md)。

Core 与 CLI 已支持精确路径及通配规则排除；图形界面尚无排除规则管理入口，也尚无任意文件夹内搜索控件。

## 验证与限制

Mac Core Debug 全套 20/20、严格 GUI Debug 全套 25/25 通过。Mac Debug 与 Release 均生成 EverythingLite.app 和 everything-lite-cli，Release 应用包版本号为 0.4.13。合成数据库迁移保留 100001 行记录的全部字段及稳定 ID；保留恢复备份后，总占用增加。具体数据见[测试记录](../TEST_REPORT.md)。

未迁移或清理日常索引，也未完成真实桌面人工交互验收。本地 Mac 构建依赖 Homebrew Qt，尚未进行独立部署、签名和公证；源码版本标签不等于已发布独立安装包。
