# 0.6.0 统一设置设计

关联 Issue #18；维护者已确认统一设置进入 0.6.0，来源同步修复先进入 0.5.5。

## 目标

以单一设置入口集中现有配置及诊断信息，使用左侧分类、右侧内容的常规设置窗口。索引状态不再使用长消息框。保留搜索主窗口布局、状态栏和选中结果。

## 页面

索引目录与来源：编辑配置目录，显示数据库活动目录的一一对应关系；历史来源归属及未启用、离线缓存单独显示。保存后调用 0.5.5 的后台同步入口；显示正在同步、扫描进度和未完成原因。

排除规则：输入和选择目录及文件，保留通配符、regex: 和 .app 包内容选项。保存使用现有验证和后台清理任务，并显示进度。

更新策略：实时/周期覆盖规则和周期长度；显示具体待更新范围及时间。

数据与存储：数据库和配置、日志、打开记录及周期队列的位置，已有存储统计与维护操作。统计按需异步加载，不在进入设置时遍历索引或文件系统。

程序状态：版本、监听对象与后端、工作任务、最近缓存统计、索引状态及具体待更新范围；只读可滚动、选择和复制，提供手动刷新。

日志：查看按日索引更新日志和现有保留设置，显示保留期限与文件位置；复用已有日志操作。

## 实现约束

优先复用现有编辑控件与任务回调；只为嵌入页面提供小范围接口，不重写搜索、来源身份和存储实现。保持原有配置键兼容。设置页面的保存和状态刷新不触发搜索，不改变活动结果或选择。维护进行时禁用冲突操作，并保留未保存输入。工具菜单的旧入口定位统一设置中的相应页面，偏好设置快捷键打开同一窗口。

## 验收

验证分类切换、旧入口定位、所有已有设置可见且能保存、重启持久化、长路径和大量状态可滚动、维护互斥和异步加载、当前搜索及选择保持不变。使用独立临时配置和数据库。0.6.0 必须同时修复已有分级更新的父目录事件边界，并通过完整 Core/GUI Debug 回归和 Mac 构建后交付。
