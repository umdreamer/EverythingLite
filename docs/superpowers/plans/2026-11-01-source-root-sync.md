# 0.5.5 索引目录与来源同步计划

关联 Issue #17；已确认版本 0.5.5。

目标：保存和启动时同步配置根目录到数据库的活动目录表。历史来源继续保留作为缓存，不因移除配置而删除文件记录。配置目录、嵌套历史来源和非活动缓存分别显示。

- [x] 使用临时数据库复现保存后新目录未注册和空列表重启恢复默认目录的问题。
- [x] 在 Database 增加原子活动目录同步和读取，规范绝对路径，去重；失败回滚，缓存及来源身份不变。
- [x] 启动及保存后安排后台同步；新增目录进入现有扫描调度；维护或工作线程占用时等待；不刷新当前查询。
- [x] 设置总览区分活动目录、所属历史来源和未启用缓存；目录列表不再混为一谈。
- [x] 覆盖新增、删除、空列表、重启、离线、重复路径、失败回滚和保留缓存的测试。
- [ ] 按提交粒度记录测试；完成 Core/GUI Debug 回归及 Mac 构建后，更新版本文档并交付标签。

实现复用现有 SQLite 连接、索引工作线程及扫描重试机制，不合并或删除历史文件记录，不修改真实日常数据库用于测试。
