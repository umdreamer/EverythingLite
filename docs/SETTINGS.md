# 设置与索引更新

Everything Lite 通过 Vibe Coding 方式开发。macOS 0.6.0 使用“工具 → 设置…”集中管理配置和状态；原有工具快捷入口定位同一个设置窗口，主搜索界面继续保留。

## 页面

“索引目录与来源”显示配置目录、数据库活动来源及归属关系。保存后后台同步清单，新增目录自动扫描。移除目录保留离线和历史缓存，未启用缓存不混入 GUI 搜索；配置目录数量不必等于保留来源总数。重新加入可访问目录后会更新该目录。

“更新策略”设置周期和目录覆盖规则。普通目录实时更新；点号路径、Finder 隐藏项目及用户 Library 默认每 15 分钟更新。间隔可设为 1 至 10080 分钟。目录规则支持直接输入和选择，路径必须是不同的绝对路径；最具体的目录规则优先。应用自身数据库及 SQLite 辅助文件、打开记录、索引日志、偏好文件、当前应用和识别到的本项目构建输出忽略自动事件，源码目录不自动排除。

首次索引、明确的完整补偿和手动重建仍扫描配置范围并遵守排除规则。普通父目录事件不提前更新周期子目录。周期范围在到期前保留旧缓存；到期后仍不能读取的范围继续保留缓存，并记录原因。持续变化不会无限推迟最初任务，扫描中新增事件保留新的代次。当前搜索不会被后台更新替换；下一次主动搜索读取新索引。

“排除规则”保留精确路径、`*`、`**`、`?` 和 `regex:`，目录及文件路径可输入或选择。保存时显示进度，完成后留在本页，便于继续编辑。程序包内容索引开关也位于此页。

“数据与存储”列出实际数据位置并按需异步读取空间状态，保留格式压缩及空间整理入口。维护操作完成前禁止冲突操作。统计字节数不等于文件系统独占物理占用，详见[索引存储](INDEX_STORAGE.md)。

“程序状态”包含索引与程序状态、配置详情与数据位置、最近搜索诊断三个页签。文本可滚动、选择及复制；刷新按钮按需读取状态。当前索引任务单独显示进度，不刷新搜索结果。

“日志与保留设置”显示按日索引更新记录、待更新范围、保留期限和清理入口。搜索关键词日志仍仅存于窗口内存，索引日志不记录查询词。删除行为和字段说明见[日志说明](SEARCH_STATUS_LOG.md)。

## 数据位置

索引和设置位于应用包外，升级程序不清除配置。数据与存储页及程序状态的配置详情页显示当前使用的准确路径。

macOS 新索引默认位于 `$HOME/Library/Application Support/Everything Lite/everything-lite.db`；若兼容位置已经有数据库，则继续使用它，包括 `$HOME/Library/Application Support/CICHI/Everything Lite/everything-lite.db` 与 `$HOME/Library/Application Support/CICHI/EverythingLite/everything-lite.db`。`EVERYTHING_LITE_DB` 可指定其他数据库。周期队列位于当前数据库旁，文件名追加 `.deferred.sqlite`。

偏好设置使用 QSettings 的 `CICHI/EverythingLite` 标识，macOS 通常保存为 `$HOME/Library/Preferences/com.CICHI.EverythingLite.plist`。打开记录和索引日志使用 Qt 的应用数据位置，准确位置以设置页为准；它们不随索引重建被清除。

文件索引、队列、日志、偏好及诊断可能含本机路径。公开材料应采用合成路径并移除个人内容，见[隐私规范](PRIVACY.md)。
