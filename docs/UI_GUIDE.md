# 界面与操作（0.4.16-fixbug）

## 主窗口与搜索

窗口包含搜索框、文件/文件夹过滤器、匹配路径、显示隐藏项目、指定文件夹范围、索引范围栏、结果表格及状态栏。启动时结果列表为空；普通编辑结束后等待 800 ms 自动搜索，输入法组词期间暂停计时。Enter 可立即搜索，但候选组词活跃时不应当作搜索动作。选择“指定文件夹…”时，未索引目录会询问是否加入索引；同意后只索引该目录并在完成后搜索，拒绝后不搜索。“清除范围”恢复全索引搜索。切换范围会立即清空旧结果。离线来源的保留记录仍可按范围搜索。

“显示隐藏项目”默认开启。关闭后，搜索会过滤点号开头的文件或文件夹、它们的子项，以及 Finder 标为隐藏的对象及其子项。Finder 隐藏标记随扫描写入现有索引字段；旧索引中的这类标记须在对应目录重新扫描后才完整。关闭选项不会删除索引记录。选项保存在本机设置中。

搜索在 `SearchWorker` 的专用线程中执行，期间保留旧结果。状态栏显示已加载结果数与后台查询用时；过期请求结果被丢弃。此处描述源码调度逻辑，中文输入法、窗口响应和退出行为仍需人工验收。Trace 模式的同步探针可能影响响应，详见 [搜索诊断](SEARCH_DEBUG.md)。

表格默认显示名称、所在位置、大小、修改时间。滚动接近底部时继续加载，每批 1000 条。表头排序作用于已加载结果，不代表全部数据库匹配项的全局排序。状态栏中的索引对象数量也不等于当前查询匹配总量。

## 文件与编辑

文件菜单提供新搜索窗口、打开、所在位置、打开方式、快速查看与导出已加载结果。Mac 使用 Finder 与系统 Quick Look，打开方式按应用名称调用系统工具。Linux 文件定位使用 FileManager1，失败时打开父目录并提示；打开方式选择本地可执行程序；快速查看优先使用 GNOME Sushi，缺少服务时展示 Qt 基础预览。CSV 只导出已加载模型，不能当作完整匹配集合。

结果支持多选。复制路径或名称把所有选中项目以换行分隔复制到剪贴板。导出和剪贴板内容可能包含个人路径，公开分享前必须检查。

## 视图、搜索与书签

View 菜单可切换状态栏、索引范围栏、过滤栏并重置表格布局。Search 菜单提供 Match Path 与 All / Files / Folders；查询中显式 `type:` 优先于下拉范围。其他搜索能力以 [搜索语法](SEARCH_SYNTAX.md) 为准。

书签保存查询、文件/文件夹类型、指定文件夹范围、Match Path 和排序状态，并由 QSettings 持久化。旧书签没有指定文件夹字段时按全索引搜索。当前整理功能以删除为主，不提供完整书签编辑器。

## 索引与诊断

工具菜单提供索引目录配置、重建索引、排除规则、索引存储、索引状态和最近搜索诊断。Preferences 当前进入索引目录配置，不是完整配置中心。“排除规则…”可手动输入或选择精确目录与文件路径，并编辑文件夹与文件过滤器；通配符和 `regex:` 可混用。手动路径可指向暂时离线的位置。无效规则会在窗口内显示错误，不保存。保存新增排除项会清理命中索引；放宽规则后须重建索引才能补回此前排除的记录。

“索引存储…”在后台读取主库、空闲页、WAL、SHM、备份及总占用。优化格式和仅整理空间均须明确选择；实际迁移或整理会保留恢复备份，优化格式升级后旧程序不能写入。操作期间显示当前阶段，可请求取消；格式提交后取消整理不会撤销格式升级。备份删除只接受列表中明确选中的精确应用备份，删除前须验证当前索引和至少一份未选中的独立恢复备份。已经删除的备份不能通过取消恢复。详情见[索引存储](INDEX_STORAGE.md)。

索引状态和最近搜索诊断会展示数据库、根目录或关键词等本地信息。测试仅使用合成目录；更换数据库不会自动更换 QSettings 中的索引范围。

搜索结果的“缓存结果（更新未完成）”表示来源曾完整索引，但最近一次扫描未完成；旧记录仍可搜索，内容可能过期。状态栏先显示“索引更新重试中”，重试耗尽后才提示“部分索引未更新”。索引条数统计读取失败不会被当作索引同步失败。受影响范围和原因可在“工具 → 索引状态”查看。

排除规则保存时显示已检查条数、总条数和耗时；完成清理及提交后才关闭窗口。手动重建显示目录序号、当前目录、已处理条数和耗时。由于扫描总条数事先未知，重建进度条为活动状态，不提供估算百分比。未识别的来源默认显示“本地磁盘”；完整重建会尝试识别本地、NAS 或外置存储，识别失败不会据此删除缓存。

`.app` 目录默认只索引为一个程序包，不索引内部文件；搜索结果在名称后标示“程序包”并显示图标。“排除规则…”中的“索引 .app 程序包内部文件”可改变此行为，开启后自动重建索引，关闭后立即清理现有包内记录。升级前已有的包内记录须保存规则或重建索引后清理。

## 快捷键

Command+N 新建窗口，Command+O 打开选中项，Command+F 聚焦搜索框，Command+A 全选已加载结果，Command+, 打开 Preferences，Command+Q 退出。Space 调用 Quick Look，结果列表中的 Return 打开当前项目。实际按键及焦点行为需要在目标系统上人工确认。

Linux 使用 Qt 标准快捷键，常见为 Ctrl+N、Ctrl+O、Ctrl+F、Ctrl+A；Space 为快速查看。命令行程序名为 everything-lite-cli，GUI 显示名称为 Everything Lite，GUI 文件名为 EverythingLite。
