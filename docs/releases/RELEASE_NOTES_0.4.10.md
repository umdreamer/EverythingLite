# Everything Lite 0.4.10 发布说明

## 变更范围

启动查询调整记录。

本说明来自后续源码包，缺少独立 0.4.10 源码快照。下述内容仅转述当时发布记录，不能据此确认该版本完整源码或原始发布状态。

记录称启动时停止自动执行空关键词查询，并复用搜索服务，减少每次查询的初始化。文件系统刷新在空输入、防抖等待或输入法组词期间延后，继续保留 800 ms 和 Enter 搜索逻辑。

当时查询执行仍在 GUI 主线程；后续 0.4.11 把服务初始化和搜索移至专用线程。
