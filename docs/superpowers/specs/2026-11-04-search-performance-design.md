# 搜索性能回归修复设计

类别为 Bug；维护者已确认版本 0.6.1，仅发布修复标签。关联 Issue #19、#20，各提交只引用其中一条。

## 已授权范围

针对输入结束后结果迟迟未出现，保留现有界面、查询语义、排序、分页、离线缓存及排除规则。只修复后台周期更新的额外计算与短词查询访问路径，不新增功能或改索引格式。

## 方案比较与选择

回退整个 0.6.0 会丢失已验收设置与更新功能；自动迁移真实数据库会增加发布范围且不能直接解决短词查询计划。采用局部修复：规范路径用组件边界比较，避免反复构造 filesystem 对象；保留原有扫描范围、Finder 隐藏属性和删除保护；手动完整重建保持权威快照。后台事件任务完成后不无条件全库计数。

传统索引的普通短名称查询使用现有名称索引有序扫描，再读取匹配文件的来源与属性。仅适用于索引存在、非 FTS 且非路径/文件夹查询的场景；其他查询维持原访问路径。不增加数据库结构或关键词日志。

## 验证

先写失败测试，覆盖配置来源下的中文短词查询计划及排序/分页、实时/周期扫描及隐藏属性变化的缓存保护、隐藏属性和覆盖规则、更新后不全库计数。性能比较使用同一合成夹具和同一编译模式，不用不同选择性词项推断加速倍数。真实数据库仅允许受限只读查询，不扫描文件系统或写入。完成完整 Core/GUI Debug、Mac 构建、隐私检查、独立代码审查后再合并。
