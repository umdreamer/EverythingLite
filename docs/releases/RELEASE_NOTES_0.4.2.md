# Everything Lite 0.4.2 发布说明

## 变更范围

文件事件与前台查询分离。

文件监听同步完成后不再无条件立即启动前台搜索，而是使用独立的 1.8 秒静默刷新定时器。文件变化重启刷新计时，前台查询仍在执行或待处理时延后刷新。

该调度用于降低持续文件事件反复重启查询的影响。历史版本保留此前的请求编号与取消机制；后续版本已调整查询执行线程及取消策略。监听稳定性仍需在目标系统上验证。
