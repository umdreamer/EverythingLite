# Everything Lite 0.4.16

Everything Lite 是 Vibe Coding 产物，代码由提示驱动的 AI 生成和迭代，非个人逐行手工编写。本版本采用 MIT 许可证，仅在本地提交和标记；未发布到 GitHub。

本版本默认把尚未识别物理类型的索引来源显示为“本地磁盘”。完整重建索引时，应用尝试从稳定的 macOS 卷信息识别本地、NAS 或外置存储，并更新来源类型；该检查不会自动把旧缓存绑定到新的来源身份。

保存排除规则时，窗口显示已检查条数、总条数和耗时。规则未变化时跳过重复的全库清理，但仍更新策略版本，防止旧扫描提交。手动重建索引时，独立窗口显示当前目录、目录序号、已处理条数和耗时。扫描总量事先未知，因此进度条不显示估算完成百分比。

`.app` 目录默认作为单个程序包索引，结果显示程序包标记和图标，包内文件默认不进入索引。在“排除规则”中可以开启包内索引；开启后自动重建，关闭后清理现有包内记录。升级前缓存的包内记录需要保存规则或重建索引后清理。

测试与构建结果见[测试报告](../TEST_REPORT.md)。合成测试不能代替真实大索引、NAS、外置设备及 Finder 桌面交互验收。
