# 分级索引更新设计

## 目标与范围

0.6.0 在 macOS 图形界面为现有索引目录增加分级更新。普通用户目录按现有监听事件增量更新；隐藏目录及程序数据目录的变化合并后周期更新，默认 15 分钟，间隔可调整。用户可针对目录覆盖实时或周期策略。手动重建继续遵守索引目录与排除规则，扫描范围不受周期队列限制。

## 分类与边界

按路径组件及最深匹配的用户覆盖规则分类，不因单纯名称相似而把普通用户目录当作应用数据。默认覆盖用户目录内的点号目录、Finder 隐藏目录和 macOS 用户 Library 目录。Finder 属性无法读取时保守排队并说明原因；不在界面线程等待网络文件系统。精确忽略应用自己的数据库及其 SQLite 辅助文件、打开记录、索引日志和当前应用构建输出的变化；源代码目录不自动排除。忽略规则只影响监听事件，不删除数据库记录，也不改变手动重建范围。

## 调度与恢复

周期队列按来源和路径分开，合并同一来源内被祖先覆盖的范围；首次变化确定截止时间，持续变化不能无限推迟更新。队列达到上限时只合并为同来源范围的补偿任务。待处理范围和截止时间持久化，任务确认成功后才移除；异常退出后重新读取。失败范围继续使用现有重试与日志机制，保持缓存。多个窗口不得丢失彼此写入的待处理任务；持久化错误时保留内存任务并提示。

文件监听溢出、来源上线和明确的完整重建需要可靠的补偿扫描，不能因忽略单个文件事件而丢失。后台更新不触发当前查询重跑，也不清空现有结果或选中行。扫描线程忙时到期任务排队，避免阻塞界面；仅跳过精确属于应用运行数据的事件。

## 设置与状态

在索引设置中显示周期和目录覆盖规则，允许输入及选择路径；验证绝对路径并持久化。设置预览可解释路径为何属于实时、周期或应用自身变化。状态栏不频繁刷新，索引状态和日志列出待更新范围、时间与原因；不记录搜索词。

## 验收

使用隔离的合成目录、独立数据库和可控时钟验证分类、最长路径覆盖、周期合并、实时事件、事件风暴、持久化与多窗口、重启恢复、失败重试、监听溢出、手动重建、应用自身变化过滤、网络及不可读路径、活动搜索与分页稳定性。Mac GUI 和 Core Debug 全量测试以及构建通过后，按 Issue 工作流合并发布。不得使用真实个人索引作为测试数据。
