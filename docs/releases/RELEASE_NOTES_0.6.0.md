# Everything Lite 0.6.0

本功能版本新增分级索引更新和统一设置，基于 0.5.5 的活动目录同步修复。项目使用 MIT 许可证，通过 Vibe Coding 方式开发，并非个人逐行手工编写。

## 分级更新

普通目录实时增量更新；点号路径、Finder 隐藏项目及用户 Library 默认每 15 分钟合并更新，可设置 1 分钟至 7 天，并为目录指定实时或周期覆盖。周期任务保存在独立的小型 SQLite 队列中，合并同来源范围，完成对应代次后才确认；重启后继续处理。

父目录事件遵守子目录策略，不提前刷新周期目录，也不删除被延后范围的缓存。应用自身数据库、日志、偏好及当前构建输出不触发重复扫描。首次索引、明确的完整补偿和手动重建仍扫描配置范围并遵守排除规则。不可读目录保留缓存和具体原因，其他可读目录继续处理。后台更新不会替换当前查询或选中行。

## 统一设置

“工具 → 设置…”提供索引目录与来源、更新策略、排除规则、数据与存储、程序状态、日志与保留设置六类页面。索引状态改为可滚动、可复制的页面，集中显示配置、数据位置和最近搜索诊断。活动目录和归属、未启用缓存分开显示。存储统计按需异步加载，排除保存和现有维护操作继续复用原流程。

## 升级与验证边界

已有目录配置、排除规则、索引格式和离线来源身份继续使用；本版本不自动执行格式压缩或删除历史备份。自动验证使用合成目录及隔离数据库、配置；真实大型索引、NAS、Linux 桌面及独立 Qt 部署、签名、公证不在本轮验收范围内。本机应用依赖构建环境的 Homebrew Qt，不能作为独立安装包分发。

实际构建与测试结果见[测试记录](../TEST_REPORT.md)，操作和数据位置见[设置说明](../SETTINGS.md)。
