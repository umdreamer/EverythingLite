# Everything Lite 0.4.3 发布说明

## 变更范围

输入规范化与结果诊断。

GUI 默认调用与 CLI 相同的搜索核心入口，结果更新主要由 request ID 控制。GUI 输入执行 NFC 规范化并移除部分零宽格式字符。

增加最近搜索诊断，展示输入原文、规范化文本、UTF-8、范围、Match Path、请求编号、执行模式、返回数量、模型数量及耗时。该窗口用于区分核心与显示层状态，不独立证明根因。

诊断内容可能包含关键词与路径。公开复现应使用合成输入 `砀例甲`、`示例工匠`，不能上传真实诊断截图。

本说明保留功能演进，不沿用个人机器数据或历史通过率作为当前验证结果。未复测的行为不得标记为通过。当前构建步骤见 [开发指南](../DEVELOPMENT.md)，验证范围见 [测试说明](../TEST_REPORT.md)，版本来源见 [历史版本](../history/VERSIONS.md)。

公开复现使用独立数据库及合成目录；不上传日常索引或原始 Trace。当前运行方式应按 0.4.11 文档执行，旧版本策略仅用于理解演进。
