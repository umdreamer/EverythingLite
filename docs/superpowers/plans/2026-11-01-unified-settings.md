# 0.6.0 统一设置实施计划

关联 Issue #18，目标版本已确认 0.6.0。基线包含 0.5.5 的来源同步修复。

- [x] 复现索引状态使用长消息框，添加统一窗口及导航行为测试。
- [x] 新增 SettingsDialog：左侧分类、右侧可滚动页面，页面按需创建，关闭后保持后台任务安全。
- [x] 在 main_window_settings.cpp 组合已有目录、排除、存储与日志控件，菜单旧入口定位同一设置窗口。
- [x] 索引状态、配置详情和搜索诊断使用只读可复制文本页面；不通过长消息框展示。
- [x] 保存目录复用来源同步入口，目录活动来源与历史/离线缓存分区显示。
- [x] 保留现有编辑验证和保存进度；排除规则在页面内保存，禁止冲突维护操作。
- [x] 覆盖来源保存、设置持久化、长状态可滚动、异步存储加载、菜单定位及搜索选择稳定性。
- [ ] 每个提交只关联本 Issue；完成独立审查、GUI/Core Debug 全量回归及 Mac 构建后接入 release/v0.6.0。

不改变搜索引擎或数据库架构。现有编辑器通过少量嵌入接口复用，保留主搜索界面。0.6.0 发布还必须解决 Issue #16 的分级更新父目录事件边界。
